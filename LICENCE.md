## Ce que cela signifie concrètement

**Les versions déjà publiées restent sous MIT, définitivement.** Une licence accordée ne se
révoque pas : quiconque a reçu la 2.6.5 ou une version antérieure conserve les droits que MIT lui
donne, sans limite de durée. Le passage à la GPL ne vaut que pour les versions suivantes.

**À partir de la 2.6.6**, MG4Control est un logiciel libre sous GNU General Public License
version 3 ou, à votre choix, toute version ultérieure. Vous pouvez l'utiliser, l'étudier, le
modifier et le redistribuer — à la condition que toute version modifiée que vous distribuez le
soit elle aussi sous GPL, code source inclus.

**L'avis MIT est conservé** parce qu'une partie du code présent dans les versions GPL a d'abord
été publiée sous MIT, y compris des contributions de tiers. MIT autorise le sous-licenciement, ce
qui rend ce basculement possible, mais impose de maintenir son avis de copyright — c'est l'objet
du fichier [`LICENSE.MIT`](LICENSE.MIT), qui reste valable pour ce code.

licences, le logiciel est fourni **sans aucune garantie**, et son utilisation relève de votre
seule responsabilité.
